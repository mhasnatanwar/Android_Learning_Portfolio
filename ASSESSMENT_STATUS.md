## Commit guidance

Use small, truthful commits as work is completed. Good examples:

- `Add authentic Module 2 tip calculator output evidence`
- `Explain state hoisting trade-offs in Module 2 analysis`
- `Document navigation and adaptive layout decisions`
- `Add verified Android Developers badge evidence`

Do not rewrite dates or manufacture a semester-long history. Authentic recent commits are better than fabricated evidence.
